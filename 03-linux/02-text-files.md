# Урок 2. Просмотр и редактирование текстовых файлов

## Базовые команды чтения и правки:
- `cat <файл>` — быстро вывести всё содержимое файла прямо в окно терминала (удобно для небольших файлов).
- `less <файл>` — открыть большой файл для удобного постраничного чтения (не засоряет терминал):
  - `q` — выйти из режима просмотра.
  - `/<текст>` — поиск слова по файлу (`n` — следующее совпадение, `N` — предыдущее).
  - `g` — перейти в самое начало файла.
  - `G` — перейти в самый конец файла.
- `nano <файл>` — открыть файл в простом консольном текстовом редакторе (если файла нет, он создастся при сохранении):
  - `Ctrl + O`, затем `Enter` — сохранить изменения.
  - `Ctrl + X` — выйти из редактора.

## Стандартные потоки ввода-вывода (stdin, stdout, stderr)

В Linux любая программа работает с тремя потоками данных:
- **0 — `stdin` (Standard Input):** стандартный ввод (по умолчанию с клавиатуры).
- **1 — `stdout` (Standard Output):** стандартный вывод результата (по умолчанию на экран).
- **2 — `stderr` (Standard Error):** поток ошибок (по умолчанию тоже на экран, но отдельно от обычного вывода).

### Перенаправление потоков в файлы:
- `<команда> > <файл>` — записать обычный вывод (`stdout`) в файл (**перезаписывает** файл полностью).
- `<команда> >> <файл>` — дописать обычный вывод (`stdout`) в **конец** файла.
- `<команда> 2> <файл>` — записать только сообщения об ошибках (`stderr`) в файл (перезапись).
- `<команда> 2>> <файл>` — дописать ошибки (`stderr`) в конец файла.
- `<команда> < <файл>` — подать содержимое файла на вход программе (`stdin`) вместо ручного ввода с клавиатуры.

### Комбинированный пример:
`./script.py > out.txt 2> err.txt < input.txt` — берет данные из `input.txt`, результат пишет в `out.txt`, а ошибки сохраняет в `err.txt`.

## Подсчет строк, слов и байтов (`wc`)

- `wc <файл>` — вывести сразу три числа для файла: количество строк, количество слов и размер в байтах.
- `wc -l <файл>` (*lines*) — посчитать **только количество строк** (часто используется для подсчета ошибок в логах).
- `wc -w <файл>` (*words*) — посчитать **только количество слов**.
- `wc -c <файл>` (*characters/bytes*) — посчитать **только размер файла в байтах**.

## Конвейер (`|` — pipe)

- `команда1 | команда2 | команда3` — передать стандартный вывод (`stdout`) первой команды напрямую на стандартный ввод (`stdin`) следующей без создания промежуточных файлов.
- Примеры связок:
  - `ls /etc | wc -l` — посчитать, сколько файлов и папок лежит в `/etc`.
  - `ls -lh /etc | less` — просмотреть длинный список файлов `/etc` постранично.
  - `cat log.txt | grep "ERROR" | wc -l` — найти все строки с ошибкой и сразу посчитать их количество.

## Отдельные полезные команды и ключи: `grep -i` и `date`

- `grep -i "<слово>"` — найти в тексте строки с нужным словом **без учета регистра** (ключ `-i` означает *ignore case* — найдет одновременно `ERROR`, `Error` и `error`).
- `date` — вывести текущую системную дату и время в терминал.
- `date >> <файл>` — добавить отметку текущей даты и времени в самый конец лога или отчета.
