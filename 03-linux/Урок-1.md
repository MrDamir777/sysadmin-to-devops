# Установка Ubuntu 24.04 в VirtualBox

- **Скачал ISO:** Ubuntu 24.04.5.1 Desktop (amd64).
- **Настройки ВМ:** 4 ГБ ОЗУ, 2 CPU, 40 ГБ диск, контроллер VBoxSVGA.
- **Установка:** выбрал «Стереть диск», раскладка English (US), пользователь `damir`.
- **Проблемы:** 26.04 зависала на заставке. 24.04 установилась без проблем.
